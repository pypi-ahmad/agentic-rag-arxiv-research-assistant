# Installation

This page takes you from fresh clone to runnable notebook environment.

If Ollama and required models are not installed yet, complete [Prerequisites](prerequisites.md) first.

---

## 1) Clone repository

```bash
git clone https://github.com/pypi-ahmad/agentic-rag-arxiv-research-assistant.git
cd agentic-rag-arxiv-research-assistant
```

---

## 2) Pull required Ollama models

```bash
ollama pull qwen3-embedding:0.6b
ollama pull granite4.1:8b
```

Optional models used in extended notebooks:

```bash
ollama pull qwen3-embedding:4b
ollama pull qwen3.5:4b
ollama pull glm-ocr
```

Verify:

```bash
ollama list
```

---

## 3) Create Python environment with `uv`

```bash
uv python install 3.13.13
uv venv --python 3.13.13
source .venv/bin/activate
```

---

## 4) Install dependencies

```bash
uv pip install -r requirements.txt
```

Quick check:

```bash
python --version
uv pip list | grep -E "faiss|langgraph|rank-bm25"
```

---

## 5) Register Jupyter kernel

```bash
.venv/bin/python -m ipykernel install --user --name agentic-rag-env --display-name "Agentic RAG"
```

---

## 6) Launch Jupyter

```bash
jupyter notebook
```

Open `notebooks/01_naive_rag.ipynb` and select the `Agentic RAG` kernel.

---

## 7) (Optional) Build full tutorial PDF

```bash
uv run python scripts/build_tutorial_pdf.py
```

Output:

```text
docs/assets/agentic-rag-full-tutorial.pdf
```

---

## Minimal smoke test cell

```python
import sys
import faiss
import ollama

print("Python:", sys.version.split()[0])
print("FAISS:", faiss.__version__)

models = [m.model for m in ollama.list().models]
print("Models:", models)

assert any("qwen3-embedding" in m for m in models), "Missing qwen3-embedding model"
assert any("granite4.1:8b" in m for m in models), "Missing granite4.1:8b model"
print("Setup OK")
```

## Repository structure (high-level)

```text
agentic-rag-arxiv-research-assistant/
├── notebooks/                      # 01-09 tutorial notebooks
├── src/                            # shared pipeline modules + rag_v2 modules
├── artifacts/                      # metrics/results/indexes/traces
├── docs/                           # MkDocs tutorial documentation
├── requirements.txt
└── mkdocs.yml
```

### Committed vs generated artifacts

- Committed: benchmark JSONs and reference outputs used by docs.
- Generated during runs: many runtime artifacts (for example FAISS binaries, notebook-specific outputs, backend-specific files).
- `artifacts/faiss_index/` is ignored in git and regenerated by running notebook 01.
