# Agentic RAG ArXiv Research Assistant

End-to-end tutorial and reference implementation for RAG evolution on ArXiv ML/AI papers:

1. Naive FAISS RAG
2. Advanced hybrid + rerank RAG
3. Agentic CRAG (LangGraph)
4. GraphRAG (ChromaDB + Pinecone + Agentic GraphRAG)

Primary benchmark baseline is now **4,000 papers** (HuggingFace source, ML-filtered).
Historical **600-paper** results are preserved for side-by-side comparison.

## Quick Start

```bash
git clone https://github.com/pypi-ahmad/agentic-rag-arxiv-research-assistant.git
cd agentic-rag-arxiv-research-assistant

uv venv --python 3.13.13
source .venv/bin/activate
uv pip install -r requirements.txt

# Required Ollama models
ollama pull qwen3-embedding:0.6b
ollama pull qwen3-embedding:4b
ollama pull granite4.1:8b
ollama pull granite4.1-guardian:8b
```

## Notebook Order

Run in this exact order:

1. `notebooks/01_naive_rag.ipynb`
2. `notebooks/02_advanced_rag.ipynb`
3. `notebooks/03_agentic_rag_langgraph.ipynb`
4. `notebooks/04_graph_rag.ipynb`
5. `notebooks/05_hybrid_rag.ipynb`
6. `notebooks/06_graphrag.ipynb`
7. `notebooks/07_agentic_rag.ipynb`
8. `notebooks/08_crag.ipynb`
9. `notebooks/09_multimodal_rag.ipynb`

Executed outputs are written to `notebooks/*executed.ipynb` when run via nbconvert.
